# Code of Conduct

## Our Standards

Be professional. Examples of acceptable behaviour:

- Constructive technical feedback
- Respectful disagreement
- Focusing on what is best for the project and its users

Examples of unacceptable behaviour:

- Personal attacks, insults, or derogatory comments
- Harassment of any kind, public or private
- Publishing others' private information without consent

## Scope

Applies in all project spaces: GitHub issues, pull requests, discussions, and any communication representing this project.

## Enforcement

Violations can be reported to **support@novoconsultinginc.org**. All reports will be reviewed and investigated. Maintainers reserve the right to remove comments, close issues, or ban contributors who violate these standards.
