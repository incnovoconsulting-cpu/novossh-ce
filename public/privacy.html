Privacy Policy

Effective Date: June 13, 2026 · Last Updated: June 20, 2026

Overview

NovoSSH is a privacy-first SSH terminal client for Android, iOS, Windows, macOS, Linux, and web. We believe your data is yours, and we're transparent about how we handle it.

Most importantly: All data is stored locally on your device. We don't have access to your SSH credentials, connection history, or any other data you store in NovoSSH.

What Data We Collect and Store

On Your Device (Encrypted)

When you use NovoSSH, the following data is stored locally on your device in an encrypted database:

  • SSH Connection Details — Hostnames, IP addresses, port numbers, usernames, authentication methods, SSH private keys
  • Terminal History — Command history for each connection, session duration and timestamps
  • Snippets & Configuration — Command snippets, user preferences, biometric lock settings, port forwarding rules

Encryption

  • All sensitive data is encrypted using AES-256 (EncryptedSharedPreferences on Android, Keychain on iOS)
  • SSH private keys are double-encrypted: first by the SSH library, then by platform-encrypted storage
  • Encryption keys are stored securely using the platform's secure enclave / keystore system

Analytics & Crash Reporting

We use Firebase Analytics and Crashlytics to improve the app. This collects:

  • Crash reports — Anonymous crash data (stack traces, device info) to fix bugs
  • Basic usage events — Feature usage counts (e.g., "SSH connection attempted") with no personal information

We do NOT collect: SSH credentials, connection details, commands executed, file contents, or any personally identifiable information.

What We Don't Do

  • No Cloud Syncing — SSH data stays on your device
  • No Third-Party Data Sharing — Your SSH data is never shared with vendors
  • No Ads — We don't display advertisements
  • No Behavioral Tracking — No cookies, fingerprinting, or user profiling

Internet Connection

NovoSSH requires INTERNET permission to establish SSH connections to remote servers and transfer files via SFTP.

The app does not transmit any of your stored data to our servers. It only connects directly to SSH servers you explicitly choose.

Data Retention

  • Your Control: You control when data is deleted
  • On Uninstall: All data is deleted when you uninstall the app
  • No Backup: We don't backup your data to cloud services

Third-Party Libraries

  • JSch: SSH protocol implementation (Android)
  • libssh2 / NIO.SSH: SSH protocol implementation (iOS/macOS)
  • AndroidX / Jetpack Compose: Google's Android libraries

Children's Privacy

NovoSSH is not directed at children under 13. We do not knowingly collect information from children.

Changes to This Policy

We may update this policy from time to time. Changes will be posted on this page with an updated effective date.
